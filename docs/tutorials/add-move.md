# Add a move

This tutorial adds a new Pokémon move (attack, status move or area move) and teaches it to a
species. The model is **Tackle**, the simplest damage move, with **Earthquake** (area) and
**Agility** (status) for the other shapes.

All paths are relative to `server/` unless they start with `docs/`, `tools/` or `client/`.
`<Move>` is the move name exactly as players see it (e.g. `Tackle`; spaces and hyphens are
allowed, e.g. `Sand-Attack`, `Take Down`).

Related: [edit-move.md](edit-move.md), [add-tm.md](add-tm.md), [add-pokemon.md](add-pokemon.md).

---

## 1. How a move works end to end

A move is joined by **name** across three server files and by **client icon id** with the
client:

```
data/lib/ps/config/moves/<move>.lua            MOVES["<Move>"] = { … }        config (loaded by config/skill.lua:51-52)
data/spells/spells.xml                         <instant name="script_<Move>" … script="…/scripts/<Move>.lua"/>
data/lib/ps/events/spells/scripts/<Move>.lua   onCastSpell → doCombat → doSkillDamage(cid, target, "<Move>")
data/lib/ps/config/pokemon/<species>.lua       skills = { …, "<Move>", <level>, … }
client/modules/gamelib/moves.lua               {name = "<Move>", iconItemId = <clientIconId>} + MOVES_DESCRIPTIONS["<Move>"]
```

Player path:

1. The client sends `m1`…`m16` (or `s1`…`s16`). `talkactions.xml:26` points these at
   `lib/ps/events/talkactions/skill.lua`, which picks the n-th entry of the ball's move list
   (`getPokemonSkills`, `config/pokemon.lua:1377-1399`).
2. `doPokemonUseSkill` (`systems/003-skill.lua:14-230`) checks the level (from the species
   `skills` list, line 68), energy (line 75), cooldown (line 82), target and distance, and
   accuracy.
3. `callSkillFunction` (`003-skill.lua:10-12`) runs
   `doCreatureCastSpell(pokemon, "script_" .. "<Move>")`. `SKILL_FUNCTION_PREFIX = "script_"`
   is at `others/constants.lua:28`.
4. The spell script calls `doSkillDamage` (`systems/004-skillDamage.lua:335`). That function
   reads `damage`, `damageType`, `category`, `criticalChance`, `projectile`, `effect` and
   `dType` from the config.
5. On success `003-skill.lua:205-226` says "<nick>, <Move>!", subtracts energy and stores the
   cooldown **on the ball** as item attribute `cooldownStorage` (`systems/007-cooldown.lua:13-17`).
   It then sends the cooldown to the client keyed by `clientIconId`.

Wild path: the monster XML `<attack name="Moves" interval="500"/>` → `spells.xml:5` →
`lib/ps/events/spells/Moves.lua`. That script picks a move from the species `skills`, using
`wildLevel` (or the species level) and `wildBlock`, and stores the cooldown in a **creature
storage** with the same `cooldownStorage` key (`Moves.lua:1-19`).

If `script_<Move>` does not exist, `doCreatureCastSpell` returns false
(`src/luascript.cpp:12435-12470`, case-insensitive lookup in `src/spells.cpp:256-263`). The
move then **does nothing**: no speech, no energy cost, no cooldown and no error message.

## 4. Authoritative source paths

* Field defaults and meaning: the getters in `data/lib/ps/config/skill.lua:83-226`.
* Load step: `config/skill.lua:51-80`. Every file in `config/moves/` is loaded with
  `dodirectory`, copied into `SKILLS_CONFIG`, and then **`requiredEnergy` is multiplied by
  0.75 and rounded up** (lines 76-80). Tackle's `requiredEnergy = 15` costs 12 in game.
* Use rules: `systems/003-skill.lua`. Damage: `systems/004-skillDamage.lua`. Cooldown:
  `systems/007-cooldown.lua`. Wild use: `events/spells/Moves.lua`.

## 5. Required IDs and how to find free ones

| ID | Tackle | How to pick a new one |
|----|--------|------------------------|
| `cooldownStorage` | 15086 | Highest in use is **15457**. The comment `-- last used cooldown storage = 15437` at `skill.lua:1` is stale |
| `clientIconId` | 12026 | Client item id of the icon sprite. Must be unique among moves; the highest in use are 27666-27668 |
| `iconId` | 13806 ("tackle icon") | Server id whose client id is `clientIconId` (check with the snippet in [add-pokemon.md](add-pokemon.md) §5: `13806 -> 12026`) |
| spell `words` | `*st145` | Must be unique among spells. Prefixes in use: `*st` (target, max `*st283`), `*sa` (area, max `*sa110`), `*ss` (self/status, max `*ss74`), `*sc` (max `*sc21`) |

```bash
# cooldown storages: highest values and duplicates
rg -o --no-filename 'cooldownStorage = \d+' server/data/lib/ps/config/moves | awk '{print $3}' | sort -n | tail -3
rg -o --no-filename 'cooldownStorage = \d+' server/data/lib/ps/config/moves | sort | uniq -d
# client icon ids: highest values and duplicates
rg -o --no-filename 'clientIconId = \d+' server/data/lib/ps/config/moves | awk '{print $3}' | sort -n | tail -3
rg -o --no-filename 'clientIconId = \d+' server/data/lib/ps/config/moves | sort | uniq -d
# is a cooldown key free everywhere? (it is also an item-attribute key on the ball)
K=15458; rg -n "\b$K\b" server/data --glob '*.lua' --glob '!**/_pokemon/**' --glob '!**/pokemon_backup/**' --glob '!**/moves_disabled/**'
# highest spell words per prefix
rg -o 'words="\*st\d+"' server/data/spells/spells.xml | sort -t t -k3 -n | tail -1
```

`cooldownStorage` is used as an **item attribute key on the ball**, so it must not collide
with the other ball attributes either: `ballsAttributes` (base 10000, `config/balls.lua:1-74`)
and `ITEM_ATTRIBUTES` (`config/itemsAttributes.lua`). Today `ITEM_ATTRIBUTES.LAST_USED_TM_BALL_MARK
= 15001` is written onto the ball by the TM system (`functions/player.lua:868-871`) and also
equals Acid's `cooldownStorage` (`config/moves/acid.lua:17`). Stay above 15457.

## 6. Example code

### 6.1 Config (real)

```1:20:server/data/lib/ps/config/moves/tackle.lua
MOVES["Tackle"] = {
    description = "Tackle is one of the most common and basic moves a Pokemon learns. It deals damage with no additional effects.",
    wildLevel = 10,
    makeContact = true,
    category = MOVE_CATEGORY.PHYSICAL,
    clientIconId = 12026,
    iconId = 13806,
    dType = DAMAGE_TYPE_NORMAL,
    functionName = "Tackle",
    type = SKILLS_TYPES.TARGET,
    requiredEnergy = 15,
    requiredLevel = 0,
    damage = 15,
    damageType = ELEMENT_NORMAL,
    effect = EFFECT_BLOW,
    projectile = nil,
    maxDistance = 1,
    cooldownTime = 1,
    cooldownStorage = 15086
}
```

### 6.2 Spell script (real)

```1:10:server/data/lib/ps/events/spells/scripts/Tackle.lua
local SKILL_NAME = "Tackle"

function onTargetCreature_Tackle(cid, target)
	doSkillDamage(cid, target, SKILL_NAME)
end

local combat = createCombatObject() setCombatCallback(combat, CALLBACK_PARAM_TARGETCREATURE, "onTargetCreature_Tackle")
function onCastSpell(cid, var)
	return doCombat(cid, combat, var)
end
```

The callback function name must be a global that is unique inside the spells Lua state. Use
`onTargetCreature_<MoveWithoutSpaces>`. Area moves build several combat objects with
`createCombatArea(AREA_…)` (see `scripts/Earthquake.lua:1-20`). Status moves call condition
helpers instead of `doSkillDamage` (see `scripts/Agility.lua`).

### 6.3 Registration (real)

```146:147:server/data/spells/spells.xml
		<instant name="script_Tackle" words="*st145" enabled="0" casterTargetOrDirection="1" blockwalls="1" script="../../lib/ps/events/spells/scripts/Tackle.lua" />
		<instant name="script_Agility" words="*ss1" enabled="0" casterTargetOrDirection="1" blockwalls="1" script="../../lib/ps/events/spells/scripts/Agility.lua" />
```

Area moves use no `casterTargetOrDirection`:
`<instant name="script_Earthquake" words="*sa5" enabled="0" script="…/Earthquake.lua" />`
(`spells.xml:289`). Self-buffs often use `aggressive="0" selftarget="1"`. `enabled="0"` keeps
players from casting it by typing the words; PSoul casts it by name.

### 6.4 Client (real)

```528:528:client/modules/gamelib/moves.lua
MOVES[#MOVES + 1] = {name = "Tackle", iconItemId = 12026}
```

```1313:1313:client/modules/gamelib/moves.lua

```

    dType = DAMAGE_TYPE_NORMAL,

    damage = 20,

## 7. Related dependencies

* Species: a move only appears for a Pokémon if it is in that species' `skills` (level-up),
  its `eggMoves`, a TM it learned, or Sketch/Mimic. `doCheckPokemonSkills`
  (`config/pokemon.lua:1729-1738`, called from `skill.lua:296`) prints an unknown `skills` entry.
* Egg moves: unknown names are removed silently (`config/pokemon.lua:1668-1670`).
* TMs: `TMS[...] .move` must be the move name ([add-tm.md](add-tm.md)).
* Held items boost by `damageType` (`004-skillDamage.lua:272`, [add-held-item.md](add-held-item.md)).
* Special cases are listed by name in `003-skill.lua:1-8` (`SPECIAL_SKILLS`, e.g. Dream Eater
  needs a sleeping target).

## 8. Registration steps

1. Write `config/moves/<move>.lua`.
2. Write `events/spells/scripts/<Move>.lua`.
3. Add the `<instant name="script_<Move>" words="<unique>" enabled="0" … script="../../lib/ps/events/spells/scripts/<Move>.lua"/>`
   line to `data/spells/spells.xml`. The name after `script_` must be the `MOVES` key; case is
   ignored but spaces count.
4. Append `"<Move>", <level>` to the `skills` of each species that learns it.
5. Client: add the `MOVES` and `MOVES_DESCRIPTIONS` lines in `client/modules/gamelib/moves.lua`.

## 9. Client requirements

> The client is a frozen reference (`docs/LEGACY_CLIENT_REFERENCE.md`). Change client files
> only when the feature needs it (new sprites, the data-table lines listed here), and say why
> in the commit message. See [add-client-asset.md](add-client-asset.md).

| What | Where | Used by |
|------|-------|---------|
| icon sprite with client id `clientIconId` | `client/data/things/data.dat` + `data.spr` | move bar (`game_pokemoves/pokemoves.lua:199` `setItemId`), TM window (`game_tmchoose`), level-up window (`game_advanceeffect/advanceeffect.lua:211`) |
| `{name, iconItemId}` | `client/modules/gamelib/moves.lua` `MOVES` | `getMoveNameByIconItemId` (`moves.lua:778`) → tooltip on the move bar |
| `MOVES_DESCRIPTIONS["<Move>"]` | `client/modules/gamelib/moves.lua` | Pokédex Moves tab tooltip (`game_pokedex/pokedex.lua:217`) |

Shift + click on a move icon sends `/sd <clientIconId>` (`pokemoves.lua:209-211`). The server
answers from its own config (`lib/ps/events/talkactions/client/skillDescription.lua`), so the
server description is what players read there.

## 12. Validation steps

```bash
tools/check_syntax.sh server/data/lib/ps/config/moves
tools/check_syntax.sh server/data/lib/ps/events/spells/scripts
tools/check_syntax.sh server/data/spells
python3 tools/check_references.py          # no new REAL ERROR; checks xml.script (spells.xml → file) and pokemon.move
# manual cross-check: every move has a script_ spell
rg -o --no-filename '^MOVES\["[^"]+"\]' server/data/lib/ps/config/moves | sed 's/MOVES\["\(.*\)"\]/\1/' | sort > /tmp/moves.txt
rg -o 'name="script_[^"]+"' server/data/spells/spells.xml | sed 's/name="script_\(.*\)"/\1/' | sort > /tmp/spells.txt
comm -23 /tmp/moves.txt /tmp/spells.txt     # moves without a spell (today: "Meowth Super Rocket", "Rocket Missile" - monster-only)
comm -13 /tmp/moves.txt /tmp/spells.txt     # spells without a move config (today: Feint, Final Gambit, Grudge, Me First, Spikes, Wide Guard)
```

At startup, look for these lines:

* `[Warning - Spells::registerEvent] Duplicate registered instant spell with words: *st…`
  (`src/spells.cpp:147`): your `words` collides with another spell.
* `[Warning - Event::loadScript] Cannot load script (…/scripts/<Move>.lua)`
  (`src/baseevents.cpp:200`): wrong path.
* `Unknown Pokemon Move: <Species> - <Move>`: a `skills` typo.
* In `server/logs/Error - <date>.log`: `[Error][…]: Skill - Duplicated clientIconId` followed by
  `Var 1 : <Move>` and `Var 2 : <id>`.

## 13. Test steps

GM Pokémon cannot use moves (BUG-05). Use **Tester** (`admin`/`admin`) or **Trainer**
(`player`/`player`) for the move itself and GM Admin only to create things.

1. GM: `/mypokemon <Species>,<level ≥ move level>`, then move the ball to Tester, or test with
   a species Tester already owns.
2. Tester: call the Pokémon outside a protection zone. GM: `/m Rattata` next to Tester.
3. Tester: attack the Rattata and say `m<slot>`. Expect "<Pokémon>, <Move>!", a damage line
   "Your <Pokémon> deals N damage to a Rattata.", the energy drop, and the cooldown overlay
   on the icon (P2-05/P2-06).
4. Repeat immediately: "Sorry, your Pokemon is exhaust (Ns)."
5. In a protection zone: "Your Pokemon can't use moves while you're in the protection zone."
6. Below the level: "Sorry, your Pokemon level for this move is too low (<level>)."
7. Shift + click the icon: "Move: <Move>, Power: …, Energy: …, Cooldown: …s, Type: …" (`/sd`).
8. Wild: GM `/m <a species with the move>`, and watch it yell `<MOVE>` in capitals.

## 14. Common mistakes

* No `script_<Move>` spell: the move silently does nothing (section 1).
* A `words` value duplicated from another spell. Registration fails with the duplicate warning.
* `clientIconId` copied from another move: the icon shows the other move's tooltip, and
  `getPokemonSkillByClientIconId` (used by `/sd` and `/tc`) returns only one of the two.
* `cooldownStorage` copied from another move: both moves share one cooldown on the ball.
  Live examples: Constrict/Stealth Rock 15201, Spider Web/Stone Edge 15288, Aqua Jet/Shell
  Smash 15355, Echoed Voice/Metal Burst 15426.
* Leaving out `type`. The default refers to `SKILL_TYPES.TARGET`, but the table is called
  `SKILLS_TYPES` (`skill.lua:88`), so the getter raises "attempt to index global
  'SKILL_TYPES' (a nil value)". All live moves define `type`; keep it that way.
* Typos in field names are silently ignored. `config/moves/dragon pulse.lua:16` has
  `ooldownTime = 21`, so Dragon Pulse uses the default 10 s cooldown.
* Expecting `requiredLevel` in the move file to matter. The level is the number after the
  move in the species `skills`.
* A non-unique global callback name in the spell script (`onTargetCreature_X`). The second
  script overwrites the first one's callback in the spells Lua state.

## 15. Failure symptoms

| Symptom | Cause |
|---------|-------|
| Saying `m3` does nothing at all | No `script_<Move>` spell, or the spell script failed to load |
| "Sorry, your Pokemon has insufficient energy (N)." with a GM character | BUG-05 (infinite-mana flag); use Tester |
| Empty or wrong icon on the move bar | `clientIconId` not in `data.dat`, or a client `MOVES` entry is missing |
| `[Error - Spell Interface] …/scripts/<Move>.lua:onCastSpell … attempt to call global 'onTargetCreature_…'` | Callback name mismatch inside the script |
| `[Error - LuaScriptInterface::loadFile] … data/lib/ps/config/skill.lua:77: attempt to compare nil with number` (or `:241`) at startup, followed by `[Warning - LuaScriptInterface::initState] Cannot load data/lib/` | `requiredEnergy` or `clientIconId` missing in some move file; the whole PSoul lib stops loading |
| Two moves always go on cooldown together | Shared `cooldownStorage` |

## 16. Rollback advice

`git checkout -- server/data/spells/spells.xml server/data/lib/ps/config/pokemon/<species>.lua`,
delete the new files, and restart. Existing balls keep stale cooldown attributes under the
removed `cooldownStorage` key; these are harmless. Do not reuse that key for a different move
until those balls have expired (`getBallSkillCooldown` ignores values more than one month in
the future, `007-cooldown.lua:7-10`).
