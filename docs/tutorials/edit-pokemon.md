# Edit an existing Pokémon species

This tutorial changes the data of a species that already exists: stats, types, moves, catch
chance, abilities, TMs, egg data or the wild monster. The example is **Eevee**
(`data/lib/ps/config/pokemon/eevee.lua`). To create a species, see
[add-pokemon.md](add-pokemon.md). Evolutions have their own tutorial,
[add-evolution.md](add-evolution.md), and so does catch difficulty,
[edit-catch-rate.md](edit-catch-rate.md).

All paths are relative to `server/` unless they start with `docs/`, `tools/` or `client/`.

---

## 1. What is stored where (and why it matters for existing Pokémon)

A caught Pokémon is **a ball item with attributes** (`docs/DEVELOPER_HANDBOOK.md` §8.2). The
ball stores the species *name*, level, experience, sex, nickname, special ability, TM slots,
egg move, held item and vitamins (`config/balls.lua` `doCreatePokemonBall`, lines 2088-2212).
Everything else is read from the species config **by name, at the moment it is needed**:

| You change | Existing balls affected? | Read by |
|------------|--------------------------|---------|
| `pTypes`, `atk`, `def`, `spAtk`, `spDef` | yes, at the next call/attack | `config/pokemon.lua:1271-1325`, `1452-1470` |
| `energy` | yes. Max energy is recomputed from it (`config/balls.lua:1716-1720`) | `getPokemonBaseEnergy` 1327 |
| monster XML `health` | yes. Base HP = XML health + 300 (`pokemon.lua:1472-1477`) | `getPokemonBaseHealth` |
| `skills` (names / levels) | yes, but see the TM slot warning in section 14 | `getPokemonDefaultSkills` 1369, `getPokemonSkills` 1377-1399 |
| `chance` | yes, for the next throw. Also the default market price (`pokemon.lua:1523-1526`) | `functions/ball/empty.lua:53` |
| `abilities`, `learnableTms`, `eggGroup`, `eggMoves`, `evolutions` | yes, next use | getters 1431-1605 |
| `specialAbilities` | **no**. The ability is rolled when the ball is created/caught and kept on the ball; evolving re-rolls only if the old one is not in the new list (`functions/pokemon.lua:183-185`) | `pokemon.lua:1508-1521` |
| `portrait`, `fastcallPortrait` | yes, at the next call (icons are re-sent) | `functions/player.lua:402`, `:606`, `systems/006-fastcall.lua:34` |
| `dexStorage`, `catchStorage` | **dangerous**. Every player's Pokédex status / catch count is stored under the old key | `010-pokedex.lua:74-87`, `functions/player.lua:756-765` |
| national number | **dangerous**. `ball_counter.pokemon_id`, highscores and client pictures use it | `pokemonsNumbers.lua` |
| species name | **dangerous**. Every ball stores the name | ball attribute `pokemonName` |

## 2. Files to edit

| Change | File |
|--------|------|
| stats, types, moves, abilities, TMs, egg data, portraits, catch chance | `data/lib/ps/config/pokemon/<name>.lua` (Eevee: `eevee.lua:1-30`) |
| variant of a species (e.g. `RC Eevee`) | the same file. Variants are built with `table.deepcopy` and then overridden (`eevee.lua:32-34`) |
| shiny portraits | `data/lib/ps/config/pokemon.lua` (`POKEMONS["Shiny Eevee"].portrait = 14340` at line 219, `fastcallPortrait = 12666` at line 220) |
| wild HP, look, corpse, level range, speed, XP, loot, AI | `data/monster/Pokemons/<name>.xml` (Eevee: `eevee.xml`) |
| client bar tooltip after changing `fastcallPortrait` | `client/modules/gamelib/pokemon.lua:257` (`iconItemId` must equal `fastcallPortrait`) |
| move list shown in the Pokédex | nothing extra. The server sends it (`systems/010-pokedex.lua`) |

---

## 3. Files NOT to edit

* `data/lib/ps/config/_pokemon/eevee.lua`. It looks like the real file but is a never-loaded
  historical snapshot (`docs/HISTORICAL_CODE_DIFF.md` Tree 1).
* `data/lib/ps/others/pokemon_backup/`, `others/moves_disabled/`, `systems/disabled/`, `original/`.
* `docs/reference/POKEMON.md` is generated by `tools/gen_reference.py`.
* Shiny/RC/Christmas/Easter monster XMLs do not inherit from the base XML. Edit them
  separately if you want the same wild change (`monsters.xml:591` `Shiny/shiny eevee.xml`,
  `:1148` `RangerClub/eevee.xml`).

## 4. Authoritative source paths

`data/lib/ps/config/pokemon/<name>.lua` is the only live definition of a species. The field
semantics are defined by the getters in `data/lib/ps/config/pokemon.lua:1271-1609` and by the
post-processing in the same file (lines 24-53, 1056-1070, 1611-1727). See the field table in
[add-pokemon.md](add-pokemon.md) §6.1.

## 5. Required IDs and how to find free ones

Most edits need no new id. Exceptions:

* **New portrait/fastcall picture:** a server id for `portrait` and its client id for
  `fastcallPortrait`. Convert ids with the snippet in [add-pokemon.md](add-pokemon.md) §5
  (e.g. 12834 → 10767). Never use a portrait already used by another species:

  ```bash
  rg -n 'portrait = 12834\b|fastcallPortrait = 10767\b' server/data/lib/ps/config/pokemon
  ```
* **New egg item:** see [add-item.md](add-item.md) §5, then update `eggId` **and**
  `POKEMON_NAME_BY_EGG_ID` (`config/pokemon.lua:1141` for Eevee).
* **Looktype:** `rg -n '<look type="484"' server/data/monster` shows who else uses it.

Constants you can use (verify the key exists before you use it; a typo becomes `nil`):

```bash
rg -n '^ELEMENT_[A-Z]+ =' server/data/lib/ps/others/constants.lua          # pTypes
rg -n '^POKEMON_ABILITIES\.' server/data/lib/ps/others/constants.lua       # abilities
rg -n '^\s+[A-Z_]+ = \d+,?$' server/data/lib/ps/others/constants.lua | sed -n '1,200p'   # TM_IDS / special abilities
rg -n '^POKEMON_EGG_GROUP_[A-Z_]+ =' server/data/lib/ps/others/constants.lua
```

## 6. Example code

Real line, changed to give Eevee one more level-up move (`Take Down` at 30). The move must be
a `MOVES[...]` key (`data/lib/ps/config/moves/take down.lua`):

```lua
-- data/lib/ps/config/pokemon/eevee.lua:22 (before)
    skills = { "Tackle", 1, "Quick Attack", 5, "Sand-Attack", 10, "Bite", 15, "Headbutt", 20, "Agility", 25 },
-- after: append only at the end, never insert in the middle (section 14)
    skills = { "Tackle", 1, "Quick Attack", 5, "Sand-Attack", 10, "Bite", 15, "Headbutt", 20, "Agility", 25, "Take Down", 30 },
```

Making Eevee easier to catch (see [edit-catch-rate.md](edit-catch-rate.md) for the formula):

```lua
-- eevee.lua:9
    chance = 200,   -- before
    chance = 150,   -- after: catchChance 150 instead of 200 with rateCatch = 1.0
```

Changing only a variant without touching the base form:

```32:34:server/data/lib/ps/config/pokemon/eevee.lua
POKEMON["RC Eevee"] = table.deepcopy(POKEMON["Eevee"])
POKEMON["RC Eevee"].pTypes = { ELEMENT_POISON, ELEMENT_NORMAL }
POKEMON["RC Eevee"].blockTransform = true
```

Overrides must come **after** the `deepcopy`. A change to `POKEMON["Eevee"]` placed below line
32 does not reach `RC Eevee`.

Wild-only changes go in the monster XML (`eevee.xml:2`: `experience="7" speed="255"
minLevel="20" maxLevel="30"`; `:3` `<health now="55" max="55"/>`).

## 7. Related dependencies

* `skills` and `eggMoves` entries must be moves ([add-move.md](add-move.md)).
  `doCheckPokemonSkills` prints `Unknown Pokemon Move: Eevee - <move>` at startup for an
  unknown `skills` entry (`config/pokemon.lua:1729-1738`). Unknown egg moves are removed
  silently (`pokemon.lua:1668-1670`).
* `eggMoves` of an evolved form are **replaced** by the lowest form's list
  (`pokemon.lua:1705-1716`). Edit Eevee's list to change Flareon's egg moves.
* Egg moves already present in a family member's `skills`, unique-TM moves, and extra heal
  moves are pruned (`pokemon.lua:1673-1693`).
* `Waterfall` in `abilities` is removed automatically when `Surf` is absent (`pokemon.lua:1720-1727`).
* `learnableTms = true` means "every TM" (`pokemon.lua:1596-1601`).
* Changing `pTypes` changes which `allowedElements` balls work (`functions/ball/empty.lua:188-190`)
  and which held items boost the Pokémon's moves (by move type, not by Pokémon type).

## 8. Registration steps

None. The species is already registered in `pokemonsNumbers.lua`, `pokemonsNames.lua` and
`monsters.xml`. Only renaming a species needs registration changes. Treat a rename as
"add new + migrate balls + remove old" ([add-pokemon.md](add-pokemon.md),
[database-changes.md](database-changes.md)).

---

## 9. Client requirements

> The client is a frozen reference (`docs/LEGACY_CLIENT_REFERENCE.md`). Change client files
> only when the feature needs it (new sprites, the data-table lines listed here), and say why
> in the commit message. See [add-client-asset.md](add-client-asset.md).

* A changed `fastcallPortrait` must exist in `client/data/things/data.dat`, and
  `client/modules/gamelib/pokemon.lua` must use the same value as `iconItemId`. Otherwise the
  Pokémon bar tooltip is empty (`getPokemonNameByIconItemId`, `gamelib/pokemon.lua:555`).
* A changed looktype must exist in `data.dat`.
* Stat, move, ability and chance changes need nothing on the client.

---

## 10. Database requirements

None for normal edits. If you change `dexStorage`, `catchStorage` or the number, migrate the
existing rows with the server stopped, for example:

```sql
UPDATE player_storage SET `key` = <new> WHERE `key` = 10133;   -- dexStorage
UPDATE ball_counter  SET pokemon_id = <new> WHERE pokemon_id = 133;
```

(see [database-changes.md](database-changes.md) for backup and rollback).

---

## 11. Server requirements

Restart the server. The species table is built while `data/lib` loads in every Lua state, so a
`/reload` refreshes only one state: `/reload spells` rebuilds the spells state and reloads
monsters, while `/reload actions` rebuilds the actions state, and so on
(`src/game.cpp:6341+`). After a partial reload, different systems see different data.

mentioning the file, no new `Unknown Pokemon Move:` line. `server/logs/Error - <date>.log`
should get no new `… - Unknown poke name.` entries.

## 13. Test steps

1. GM Admin: `/mypokemon Eevee,30` gives "You received an Eevee.". Call it and check the Pokédex
   view of your own Pokémon (use the Pokédex on it). The stats, moves and abilities shown come
   from the config.
2. New level-up move: `/mypokemon Eevee,29`. Tester levels it to 30 ("Congratulations! Your
   Eevee advanced from level 29 to level 30.") and the new move appears on the move bar. It
   is hidden while the level is below the required level (`functions/player.lua:387-393`).
   Using it below the level gives "Sorry, your Pokemon level for this move is too low (30)."
   (`systems/003-skill.lua:68-70`).
3. Wild change: GM `/m Eevee`. Check the level range, and after defeating it check the catch
   XP: "You earned <experience × level × 2> experience points by catching Eevee!"
   (`functions/ball/empty.lua:34-36`).
4. Catch-chance change: see [edit-catch-rate.md](edit-catch-rate.md) §13.

## 14. Common mistakes

* **Reordering or inserting into `skills`.** The talkactions `m1`…`m16` index the list by
  position (`events/talkactions/skill.lua:22-26`). TMs and egg moves are stored on the ball
  as a **slot number** (`getBallTmSlot`, `getBallEggMoveSlot`, `config/pokemon.lua:1377-1392`).
  Inserting a move shifts every later slot, so existing balls replace the wrong move. Only
  append.
* Removing `"Tackle"` from slot 1. Sketch moves assume slot 1 is Tackle (`pokemon.lua:1395`),
  and `onTmChoose` refuses to replace Tackle ("You can't replace the move Tackle.").
* Editing `_pokemon/eevee.lua` (not loaded).
* Changing `dexStorage`/`catchStorage` "to fix a pattern". `mawile.lua:13`
  (`catchStorage = 28559`) breaks the `16000 + N` pattern, but players' catch counts and the
  highscore (`systems/011-highscore.lua:1143`) are stored under 28559. Leave it.
* Overriding a variant field before `table.deepcopy`.
* Misspelled ability strings (BUG-30: `"Strenght"` in 11 species, so Strength is never available).

## 15. Failure symptoms

| Symptom | Cause |
|---------|-------|
| `[Error - LuaScriptInterface::loadFile] data/lib/ps/config/pokemon/eevee.lua:<line>: …` at startup, and later species missing | Syntax error. The directory load stops at this file (`src/luascript.cpp:735-737`) |
| `Unknown Pokemon Move: Eevee - <move>` | `skills` entry is not a `MOVES[...]` key |
| Move bar shows an empty slot | The move exists but its `clientIconId` sprite is missing on the client |
| "Your Pokemon can't learn this Technical Machine." after adding a TM | `TM_IDS` typo → `nil` in `learnableTms` |
| Field ability not offered | Ability string does not equal the `POKEMON_ABILITIES` value |
| Old balls use a different move than expected for m3/m4 | `skills` reordered (section 14) |

---

## 16. Rollback advice

* `git checkout -- server/data/lib/ps/config/pokemon/eevee.lua` (and the monster XML).
* Restart the server. `/reload` does not rebuild the species table in every Lua state
  (`docs/DEVELOPER_HANDBOOK.md` §10.3).
* If players already received balls under a changed storage/number, restore the database
  backup taken before the change ([database-changes.md](database-changes.md)).
