# Edit a move

This tutorial changes an existing move's numbers (power, energy, cooldown, range, element,
category, description) without breaking existing balls. The example is **Tackle**
(`data/lib/ps/config/moves/tackle.lua`).

All paths are relative to `server/` unless they start with `docs/`, `tools/` or `client/`.

Related: [add-move.md](add-move.md) (full field table and the end-to-end flow),
[add-tm.md](add-tm.md), [edit-pokemon.md](edit-pokemon.md).

---

## 1. What is read live and what is stored

Almost everything about a move is read **live** from `SKILLS_CONFIG[<Move>]` every time the
move is used. The getters are in `data/lib/ps/config/skill.lua:83-226`. A change therefore
applies to every Pokémon (wild and owned) after a restart.

Values stored somewhere else:

| Stored value | Where | Consequence of an edit |
|--------------|-------|------------------------|
| Cooldown **expiry time** | Ball item attribute, key = `cooldownStorage` (`systems/007-cooldown.lua:13-17`) | A new `cooldownTime` applies from the next use. Changing `cooldownStorage` drops the running cooldowns (the new key is empty) |
| Wild cooldown | Creature storage, same key (`events/spells/Moves.lua:1-9`) | As above, for wild monsters |
| The move **name** as an egg move | Ball attribute `ballsAttributes.eggMove` (`config/balls.lua:2468-2480`) | Renaming a move breaks balls that hold it as an egg move |
| The move **name** as a Sketch move | Ball attribute `ballsAttributes.sketchMoves` (`config/balls.lua:1799-1810`, used at `config/pokemon.lua:1394-1396`) | Renaming breaks Smeargle balls |
| TM learned | Ball stores the **TM id**, not the move name (see [add-tm.md](add-tm.md)) | Safe while `TMS[...].move` is updated together with the rename |
| Move slot order | Index into the species `skills` list | Changing a species' list is covered in [edit-pokemon.md](edit-pokemon.md) |

**Do not rename a move** on a live server. Change the numbers only.

## 2. Files to edit

| Change | File |
|--------|------|
| Power, energy, cooldown, range, element, category, effect, projectile, description, flags | `data/lib/ps/config/moves/<move>.lua` (Tackle: `config/moves/tackle.lua:1-20`) |
| Area shape, hit count, status effect, animation timing | the spell script `data/lib/ps/events/spells/scripts/<Move>.lua` (the `area`/`areaName` fields in the config are **not read**) |
| Level at which a species learns it | that species' `skills` list (Eevee: `config/pokemon/eevee.lua:22`, `"Tackle", 1`) |
| Client tooltip in the Pokédex | `client/modules/gamelib/moves.lua` `MOVES_DESCRIPTIONS["<Move>"]` (Tackle: line 1313) |
| Icon | `clientIconId` **and** the client `MOVES` entry (Tackle: line 528) together |

---

## 3. Files NOT to edit

* `data/lib/ps/others/moves_disabled/`: not loaded.
* `docs/reference/MOVES.md`: generated by `tools/gen_reference.py`; regenerate it instead.
* The commented `MOVES_DESCRIPTIONS` block at `client/modules/gamelib/moves.lua:782-1099`. It
  is dead; the live entries are the `MOVES_DESCRIPTIONS["…"] = …` lines after it.
* `config/skill.lua:76-80` (the global ×0.75 energy rule). Changing it rebalances every move.
* `original/`.

## 4. Authoritative source paths

| Field | Read at | Effect |
|-------|---------|--------|
| `damage` | `systems/004-skillDamage.lua:195` (`getFinalDamage`) | Against a monster (line 275-279): `damage × elementMultiplier × (level + 10) × 0.2 + (Atk − Def)` for `PHYSICAL`, or `SpAtk − SpDef` for `SPECIAL`/`STATUS`. Against a player (line 202): `damage + level × 2`. STAB +10% (line 267), held item modifier (line 271-272) |
| `damageType` | `004-skillDamage.lua:218` (element chart), `:267` (STAB), `:272` (held item) | `ELEMENT_*` |
| `category` | `004-skillDamage.lua:275` | which stat pair is used |
| `criticalChance` | `004-skillDamage.lua:283` | % chance of ×1.3 ("CRITICAL!") |
| `requiredEnergy` | `systems/003-skill.lua:75-77` check, `:213` cost | **multiplied by 0.75 and rounded up at load** (`skill.lua:76-80`). Tackle 15 → 12 |
| `cooldownTime` | `007-cooldown.lua:14` | seconds; ×2 against Pressure, ×1.1 against Stall (`003-skill.lua:217-221`) |
| `maxDistance` | `003-skill.lua:104` | "Sorry, your Pokemon is too far from the target." |
| `type` | `isPokemonSkillTypeTarget` (`skill.lua:233`) | `TARGET` needs a target ("First get a target.") |
| `wildLevel`, `wildBlock`, `makeHeal` | `events/spells/Moves.lua:11-19` | wild AI only |
| `description`, `damageText` | `/sd` (`events/talkactions/client/skillDescription.lua:5`) | text players see on Shift + click |

`damageText` (`skill.lua:111-114`) replaces the "Power" number in `/sd` only; it does not
change damage.

## 5. Required IDs

Number edits need no new IDs. If you have to change a key:

* `cooldownStorage`: pick a free one as in [add-move.md](add-move.md) §5 (highest in use is
  15457). Do this when you fix one of the shared pairs: Constrict/Stealth Rock 15201,
  Spider Web/Stone Edge 15288, Aqua Jet/Shell Smash 15355, Echoed Voice/Metal Burst 15426.
* `clientIconId`: must stay unique, exist in `client/data/things/data.dat`, and match the
  client `MOVES` entry.

```bash
rg -n "cooldownStorage = 15086\b" server/data/lib/ps/config/moves      # who else uses Tackle's key?
rg -n "clientIconId = 12026\b" server/data/lib/ps/config/moves
rg -n '"Tackle"' server/data/lib/ps --glob '*.lua' | rg -v '/config/pokemon/' | head   # name references outside species
```

## 6. Related dependencies

* `SPECIAL_SKILLS` (`systems/003-skill.lua:1-8`) lists moves by name for special rules.
* Tackle is special: it can never be replaced by a TM ("You can't replace the move Tackle.",
  `systems/018-technicalMachine.lua`) and Sketch skips it (`config/pokemon.lua:1395`).
* Held items multiply by `damageType` (`systems/046-heldItem.lua:525-539`). Changing a move's
  element changes which held item boosts it.
* TMs teach the move by name (`TMS[...].move`); the TM item description in `items.xml` repeats
  the move name and category in text (Toxic: `items.xml:22487`). Update the text if you change
  the category.

## 7. Example code

Current Tackle:

```10:19:server/data/lib/ps/config/moves/tackle.lua
    type = SKILLS_TYPES.TARGET,
    requiredEnergy = 15,
    requiredLevel = 0,
    damage = 15,
    damageType = ELEMENT_NORMAL,
    effect = EFFECT_BLOW,
    projectile = nil,
    maxDistance = 1,
    cooldownTime = 1,
    cooldownStorage = 15086
```

Example balance change (power 15 → 20, energy 15 → 16 so the in-game cost is
`ceil(16 × 0.75) = 12`, unchanged):

```lua
    requiredEnergy = 16,
    damage = 20,
```

Leave `requiredLevel = 0` alone. It is not read; the learn level is the number after the move
in each species' `skills` list (`config/pokemon.lua:1421-1430`).

None. The file is already loaded by `dodirectory` in `config/skill.lua:51-52` and already has a
`script_<Move>` spell. Keep the `MOVES["<Move>"]` key unchanged.

## 9. Database requirements

None. Running cooldowns live in `player_items.attributes` (on the ball).

## 10. Client requirements

> The client is a frozen reference (`docs/LEGACY_CLIENT_REFERENCE.md`). Change client files
> only when the feature needs it (new sprites, the data-table lines listed here), and say why
> in the commit message. See [add-client-asset.md](add-client-asset.md).

* Number changes: none. The client shows the server values through `/sd` and the cooldown
  packet (`doPlayerSendPokemonSkillCooldown`, `007-cooldown.lua:16`).
* Description: the Pokédex tooltip uses the **client** `MOVES_DESCRIPTIONS`
  (`client/modules/gamelib/moves.lua:1313`), the Shift + click text uses the **server**
  `description`. Update both. Known stale text: the client Whirlwind description is a copy of
  Tackle's (`client/modules/gamelib/moves.lua:1497`).
* `clientIconId` changes need the client `MOVES` line updated too, and a client release.

## 11. Server requirements

Restart. `/reload spells` only rebuilds the spells Lua state. `doPokemonUseSkill` runs in the
talkactions state, which would keep the old `SKILLS_CONFIG`, and the ×0.75 rule would be
applied again to any state that re-runs the lib. See `docs/DEVELOPER_HANDBOOK.md` §10.3.

## 12. Validation steps

```bash
tools/check_syntax.sh server/data/lib/ps/config/moves
python3 tools/check_references.py          # no new REAL ERROR (pokemon.move, move.iconId)
# field-name typos (unknown keys are ignored silently)
rg -o --no-filename '^\s+[a-zA-Z]+ =' server/data/lib/ps/config/moves | tr -d ' \t=' | sort | uniq -c | sort -n | head
```

The last command lists the rarest keys first. A typo shows up with a count of 1 (next to a few
rare but valid keys such as `sketchable`); compare each against the getters in
`skill.lua:83-226`. Today the only typo is `ooldownTime` from `config/moves/dragon pulse.lua:16` (Dragon Pulse therefore uses the default
10 s cooldown).

Startup log: no `[Error - LuaScriptInterface::loadFile] … skill.lua:77` (missing
`requiredEnergy`) and no `Skill - Duplicated clientIconId` in `server/logs/Error - <date>.log`.

## 13. Test steps

Use **Tester** for the move (GM Pokémon cannot use moves, BUG-05).

1. Tester: Shift + click the Tackle icon. Expect
   "Move: Tackle, Power: 20, Energy: 12, Cooldown: 1s, Type: Normal, Category: Physical, Range: 1 sqm." followed by the description.
2. GM: `/m Rattata`. Tester attacks it and says `m1`. Expect "<nick>, Tackle!" and the damage
   line "Your <Pokémon> deals N damage to a Rattata.". Compare N with the old value.
3. Say `m1` again immediately: "Sorry, your Pokemon is exhaust (Ns)." with the new cooldown.
4. Energy below the cost: "Sorry, your Pokemon has insufficient energy (12)."

## 14. Common mistakes

* Forgetting the ×0.75 rule: `requiredEnergy = 20` costs 15.
* Expecting `requiredLevel`, `area`, `areaName`, `functionName` or `iconId` in the move file to
  change anything; no server code reads them.
* Changing `damageType` but not the spell script's visual effect, or the reverse.
* Typing a field name wrongly (`ooldownTime`): it is silently ignored and the default is used.
* Renaming the `MOVES["…"]` key: every species `skills`, TM, `spells.xml` `script_` name, client
  entry, and the egg/Sketch move names stored on balls would have to change too.
* Removing `type`: the default refers to the undefined global `SKILL_TYPES` (`skill.lua:88`;
  the real table is `SKILLS_TYPES`), so `getPokemonSkillType` raises
  "attempt to index global 'SKILL_TYPES' (a nil value)".

## 15. Failure symptoms

| Symptom | Cause |
|---------|-------|
| `/sd` shows the old values | Server not restarted |
| Energy shown is lower than the file value | The ×0.75 rule (expected) |
| Two moves share a cooldown | Shared `cooldownStorage` (see section 5) |
| A move uses a 10 s cooldown regardless of the file | `cooldownTime` misspelled or missing |
| `attempt to index field '?' (a nil value)` from `config/skill.lua` getters after a rename | A species list, TM, egg move or Sketch move still uses the old name |
| `[Error][…]: skillDescription - Unknown move` and "A problem was occurred! Please contact a gamemaster…" | `clientIconId` changed on the server but not in the client `MOVES` |

---

## 16. Rollback advice

`git checkout -- "server/data/lib/ps/config/moves/<move>.lua"` and restart. Number changes leave
nothing behind. If you changed `cooldownStorage`, running cooldowns under the old key are
ignored after rollback only once they expire; `getBallSkillCooldown` also ignores values more
than a month in the future (`007-cooldown.lua:7-10`). `getCurrentTimeInSeconds` is based on the
day of the year (`007-cooldown.lua:1-4`, BUG-34), so cooldowns running across New Year end early.
