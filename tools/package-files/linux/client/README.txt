PokeNation legacy client for Linux (PSoul/PokeAimar reference client)
=====================================================================

DEVELOPMENT BUILD compiled from client/src-cpp. Version/commit: VERSION.txt, version.json.
Needs an X11 desktop with OpenGL, plus PhysFS, OpenAL, GLEW, Vorbis/Ogg runtime libraries.

  ./start_client.sh      (start the server first)

Log in with player/player (Trainer) or admin/admin (GM Admin, Tester). Connects to 127.0.0.1:7564.
Log file: ~/psoul.log. Licence: LICENSE-client.txt (MIT).
